## Schema for the product directory

Use: firm; role family; London location confirmed; programme stage; official recruitment URL; route type (vacancy / rolling / speculative / information only); public recruiting inbox where explicitly invited; eligibility; deadline; deadline source; last checked; next check; status; notes.

Never infer a current vacancy from an evergreen careers page. Separate rolling applications from a confirmed opening. Do not guess deadlines or sponsorship rules. Avoid scraped private contacts. Recheck each row before a member acts.

## A useful outreach approach

Read the firm’s work and published requirements. Write a short specific introduction, state the relevant availability, explain one credible connection to its work and follow the application instructions. If attaching a CV, verify that it is the intended version. Record the message and a reasonable follow-up date in your own tracker. Do not bulk-send the same message to every firm.
